# Info
<b>
<br>Arduino-powered 4-digit 7-segment school clock and lesson display.
<br>Cycles between current time, next lesson name, and next lesson start time.
<br>Set day, hour, and minute on startup using three buttons.
<br>Edit time later with UP/DOWN buttons.
</b>

# Wiring
<b>
<br>74HC595 shift register: D12 (data), D11 (latch), D9 (clock)
<br>Digit control: D4, D5, D6, D7
<br>UP button: D3
<br>SUBMIT button: D13
<br>DOWN button: D10
</b>
